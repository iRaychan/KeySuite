# Upgrade to KeySuite V5.00.23

Supported baseline: KeySuite V5.00.22.

Replace the files in the upgrade package at the matching paths, then reload KeySuite. The V5.00.23 service worker clears the previous KeySuite cache and activates the new version lock.

This release changes KV selector presentation and chart rendering only. It does not require a Supabase migration and does not change the frozen quotation PDF layout.
