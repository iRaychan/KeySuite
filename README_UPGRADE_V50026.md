# Upgrade to KeySuite V5.00.26 from V5.00.25

1. Back up the current V5.00.25 deployment.
2. Extract the upgrade ZIP into the KeySuite web root and replace matching files.
3. Keep all other application and data files in place.
4. Reload once with the browser cache cleared or allow the V5.00.26 service worker to activate.
5. At browser zoom 100%, regression-check CR, CHC C4/C6, ES, KV and BGF.

No Supabase deployment or database migration is required. GitHub is not required. CR MASTER, ES MASTER, existing server data, and frozen quotation PDF layout 1.08 are unchanged.
