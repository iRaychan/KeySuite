## Executed tests

- `tests/v50082/verify.cjs`: application scripts execute against the real index DOM using jsdom 26.1.0. Tests exercise real handlers, customer storage functions and Pumpset conversion. Database transports are in-memory mocks only; network calls are forbidden. `RESULTS.json` contains executed checks and eight generated descriptions.
- `tests/v50082/database.cjs`: approval-required history SQL executes in PGlite 0.3.14 (in-memory PostgreSQL). Tests cover Full/Own/None, invalid level denial, two creators, archive/current deduplication, inactive and cross-company denial, and authenticated/anonymous execution grants. Existing helper interfaces are simulated. This is not a Supabase RLS/authentication test.
- `tests/commercial-identity.cjs`: PASS 54 configuration combinations, idempotence, brandless identity and unchanged pricing/hydraulic inputs.
- `tests/v50062-brand-mapping.cjs`: PASS CHC variants, generation isolation, explicit precedence, ambiguity handling and ES isolation.
- `tests/v42859-assembly-pricing-regression.cjs`: PASS assembly/system pricing and restored-action checks.
- JavaScript syntax checks: PASS for every changed/new application module and new test script.
- Pricing, motor, coupling, baseplate, hydraulic assets and KeyStock application files are byte-identical to baseline except the specifically documented assembly description/selection changes.
