# Upgrade to KeySuite V5.00.25 from V5.00.24

1. Back up the current V5.00.24 deployment.
2. Extract the upgrade ZIP into the KeySuite web root and replace matching files.
3. Keep all other application and data files in place.
4. Reload once with the browser cache cleared or allow the V5.00.25 service worker to activate.
5. At browser zoom 100%, compare CR and KV at the same Safari window size.
6. Open Product → B.G.Reich → KV → KV 1-50 and confirm the selected model and curves finish loading.

No Supabase deployment or database migration is required. CR MASTER, ES MASTER, existing engineering data, and frozen quotation PDF layout 1.08 are unchanged.
