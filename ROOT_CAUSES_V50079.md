# Phase 01 root-cause findings

Investigated 18 November 2026 using the actual Mac Safari session, local V5.00.78/V5.00.79 source, and read-only Supabase inspection. Screenshots are supporting evidence, not proof of a particular backend failure.

| Bug | Finding | Correction |
|---|---|---|
| 009 | saveQuoteRemote rejected any save when quotationSyncMode was not `supabase`, before session recovery. A transient history failure left it in `error`, blocking otherwise valid saves. A committed save followed by a failed history refresh was also reported as failed. New unsaved quotations received a new logical UUID on each Save attempt. | Permit authenticated RPC recovery independently of history state. Accept an explicit atomic `saved` response only when its returned document ID matches the requested ID; report history refresh separately. Reuse the existing quotation-session UUID across retries. Preserve permission checks, failed drafts and server RPC locking. |
| 001 | Shared Product Curve startup selected the first `.product-curve-selector-head` in the document (the ES selector heading). insertBefore used a close button belonging to another parent, throwing NotFoundError before the curve API was exported. | Scope startup action/pole controls to the actual Product dialog. |
| 002 | A brand placeholder `-` was excluded from brand replacement candidates but remained in the first descriptive line generated by HMS. | Strip a leading placeholder from the shared description normalization when the selected brand is blank or `-`; preserve valid names and Capacity lines. |
| 003 | Costing Audit inferred source family from the selling label. Custom `HMS` was unrecognized and fell back to CHC, producing a nonexistent CHC HMS source lookup. | Resolve source family from the actual Product page and reverse its configured selling-series alias. Keep display identity separate from engineering/source identity and reuse existing pricing/margin functions. |
| 004a | BSW had a one-shot iframe model/ready exchange, vulnerable to initialization order. Shared navigation cleanup could leave the loaded iframe hidden/transparent; the BSW opener restored display but not visibility. | Bound model retries to initialization acknowledgement; restore display, visibility and opacity when opening. |
| 004b | The shared presentation layer retained an old pinned model while BSW child state changed phase. | Treat BSW curve state as fresh identity instead of reapplying a stale pinned model. Synchronize phase/float controls from the child snapshot. |
| 004c | BSW lacked a top configuration panel and had legacy BSV header text in the child adapter. | Add phase and Auto/Non-Auto controls using existing catalogue variants, retain the existing shared hydraulic model, correct BSW heading and hide the BSW panel on other families. |
| 005 | CR legacy and shared material handlers posted competing model presentations. The Product child alias collapsed CRS/CRN to CR and stale child state could override the top material control. | Keep CR/CRS/CRN aliases distinct, give the current Product material control precedence and suppress duplicate legacy posting when the shared runtime is active. Shared presentation supplies CR Series. |
| 006 | ES hardcoded Product/selector options omitted duplex; material-to-price normalization would append MS/GP to an independent duplex key. ISO options are generated from existing source configurations and already contain duplex. | Add ES duplex options/technical material profiles and preserve independent duplex keys. Preserve ISO's existing configurations without reseeding them. |
| 007 | ES Price List omitted independent duplex options. Existing ES save RPC only updates material entries already present in a product's variants array. | Expose independent options, reject saving an absent configuration explicitly, provide a separate review-only SQL append of blank configurations. Existing ISO duplex prices remain unchanged. |
| 008 | BSW multi-variant rows relied on a compressed table/flex layout; price wrappers and rarity controls could shrink/overlap, and heading rules targeted the wrong table. | Give price controls/cells stable minimum widths, use an intrinsic-width table inside the scroll container and correct the heading selector. |

## Secure saving investigation boundary

The connected KeySuite project was available to read-only inspection. The installed V5.00.37 save RPC was inspected: authenticated company/permission checks and logical-ID advisory locking remain in place; it returns the committed document on success. No RLS, authentication or database function was changed. Safari could read existing Quote History, including an entry corresponding to the reported failure screenshot. This establishes that the connection was not continuously unavailable; it does not establish the exact network/authentication condition at the earlier failed save.

No production save was attempted. There was no disposable Supabase/PostgreSQL service available, so real database persistence, RLS and simultaneous-client contention remain unverified. The repaired client defects were reproduced with controlled failure responses in Safari and Chrome. The release must not be described as a proven cure for every possible connectivity failure.
