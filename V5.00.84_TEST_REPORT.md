## Automated commands

The tests require Node.js and jsdom 26. Install jsdom in an isolated dependency directory and set NODE_PATH to its node_modules; no production credentials are used.

```sh
node tests/v50084.cjs
node tests/v50084-brands.cjs
node tests/v50083.cjs
node tests/v50082/verify.cjs
```

The original late-write defect was reproduced against V5.00.83 using v50084-brands.cjs with KEYSUITE_TEST_ROOT pointing to that baseline and EXPECT_BASELINE_DEFECT=1. Final logs are in tests/v50084-results.json. The harness supplies browser-only functions such as structuredClone/ResizeObserver and executes local scripts in JSDOM; it does not measure visual layout or operate Safari.

## Scope and data preservation

No hydraulic catalogue, source-pricing table, pricing formula, Brand Margin formula, permission policy, inventory module, database migration or database seed was changed. Legacy ES/ISO normalization can add existing default seal metadata during assembly formatting; monetary values and BOM membership were checked separately. Production records were never used for test writes.

The red field is only a frequency indication. Existing speed-adjusted estimates and missing-data behavior remain as before; this release does not establish mechanical/electrical suitability above 50 Hz.
