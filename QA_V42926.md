## Practical limits

WebKit automation was run on this Mac, not a certified test of the installed Safari application or physical iPhones. Real-device Safari acceptance and hosted two-account WebSocket/session testing remain to be done after publishing. The build does not claim those checks passed. Local fixtures use synthetic employee identities; no production employee accounts or test messages were created.

The production Supabase read was limited to the reported quotation and its schema. No V4.29.26 SQL, frontend hosting or GitHub changes were deployed. `README_UPGRADE_V42926.md` identifies the one required speed migration and the already-deployed V0.10 timestamp mapping.

## Reproduction

Serve the project locally on 127.0.0.1:8260. Use the pinned Playwright/PGlite versions in tests/v010/package.json (Chromium tests use installed Chrome). Run the suites in tests/v42926: navigation.cjs, physics.cjs, browser.cjs, touch.cjs, quotation.cjs and database.cjs. The visual.cjs script captures avatar/office/monitor previews. `window.KeyHQCampus.diagnoseNavigation()` returns read-only reachability diagnostics in a running campus.
