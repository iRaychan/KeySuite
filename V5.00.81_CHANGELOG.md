# KeySuite V5.00.81 — Phase 02 Bugs 001 and 002

Baseline: V5.00.80. No database migration or data reset is required.

- Added `commercial-identity.js`: configured commercial brand, series and model, independent hydraulic and pricing identities, explicit brandless handling, description formatting and serializable item snapshots.
- Shared curve aliases now recognize the hydraulic family even when a configured master series has another name. No HMS/BFI-specific exception was added.
- Product openings capture their commercial context instead of rebuilding it from subsequent global selection changes.
- The outer curve title reads the active frame's presentation context instead of restoring a cached title from a different series.
- ES source descriptions no longer hardcode B.G.Reich. The selected commercial identity is applied before individual/complete-set routing.
- Assembly normalization and pump description formatting use component commercial identity. Mixed components retain their own identities.
- New quotation items retain a commercial identity snapshot. Restored records retain their saved descriptions and manual edits; legacy row remapping skips explicit snapshots.
- Updated version and service-worker cache; added the resolver to offline resources.

Hydraulic data, pricing formulas, brand-margin math, fuel sharing, BOM quantity/rounding, permissions and secure-save RPCs are unchanged. Existing records are not rewritten.

See V5.00.81_TEST_REPORT.md for executed checks and remaining coverage limits.
