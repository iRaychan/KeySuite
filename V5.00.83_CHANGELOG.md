# KeySuite V5.00.83

Baseline: V5.00.82 FULL. Only customer curve-series discovery and automatic Pumpset accessories changed.

- Customer Curve Preference and Quick Selection share commercial navigation discovery. Eligible G Series has an independent selection key and retains its configured label. Configured future series can participate without adding UI whitelist entries.
- Customer price authorization remains a separate gate. Existing selection and price keys are retained.
- Automatic synchronization no longer interprets absence as a user removal. Fresh eligible drafts can size Flexible Coupling and Baseplate again.
- Explicit deletion flags still prevent automatic restoration. Baseplate now has its own Restore Auto Baseplate control and its suppression state is included in serialized assembly metadata.
- V5.00.82 flags cannot reliably distinguish intentional removal from the regression; they are retained. Use Restore Auto Coupling and Restore Auto Baseplate in affected existing drafts.

No database migration, production write or deployment was performed for this release. The inherited V5.00.82 SQL proposal remains reference material; it is not a new migration for V5.00.83.
