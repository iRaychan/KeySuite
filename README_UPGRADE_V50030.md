# Upgrade to KeySuite V5.00.30

Supported source version: V5.00.29.

1. Back up the installed V5.00.29 directory.
2. Extract the V5.00.30 upgrade ZIP over the V5.00.29 installation, preserving directory structure.
3. Reload KeySuite and clear the browser application cache if an older version label remains.
4. Confirm the login and application footer display V5.00.30.

No database migration or Supabase deployment is required.
