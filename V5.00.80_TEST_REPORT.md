## Root causes

003: readQuoteItemData's early manual-item return omitted internalRemark. getQuoteItemData previously did not restore it, so getQuoteItems/saveQuote serialized manual items without their remarks. Generic product items had a different branch retaining remarks. Stable item IDs were absent; metadata outside enumerated fields could also be discarded.

004: setQuotationEditingLocked disabled Remarks and pointer events; openItemRemark rejected sealed quotations through canEditQuotation. The corrected read-only dialog uses the existing UI and guards saving through the existing permission check.

001: selector text aliasing cached the first text-node value forever. A selector updating an existing text node could subsequently be overwritten with stale identity. Duplicate alias functions also skipped configured mappings for master brands. The selector now delegates to the existing displayModelAlias configuration resolver. This is a scoped correction, not a completed audit of all identity consumers.

002: pumpDescriptionParts in assembly.js recognized only a B.G.Reich End Suction description and otherwise generated a B.G.Reich fallback. This replaced Megaflow/other component names in complete sets. It now retains existing commercial descriptions and derives a fallback only from component metadata.
