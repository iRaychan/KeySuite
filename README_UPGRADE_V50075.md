# KeySuite V5.00.75 review upgrade

Apply this ZIP over a copy of the corrected V5.00.74 FULL build. Extract it at the application root and allow the matching application files to be replaced. For any other starting revision, use the V5.00.75 FULL archive.

Open the application in an isolated review environment. Confirm V5.00.75 in the sidebar, then verify a C4 product quotation and compare the Assembly Cost BOM table with the Assembly builder.

The C4 product action carries the selected selling brand into the quote while preserving the hydraulic model for price lookup. The Assembly Cost dialog uses the builder's BOM total for its Assembly comparison. Its Individual total still uses individually priced components.

This release is client-side. It requires no database migration or data seed.
