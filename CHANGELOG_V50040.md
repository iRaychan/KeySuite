# KeySuite V5.00.40

- Category: removed the left-panel Edit and hold-to-delete controls and their handlers. Category selection and the right-panel Hold 3s to Edit remain available.
- Quotation: added independent SST and percentage or RM discounts. Percentage adjustments use the original subtotal. Blank and zero values are stored distinctly in the existing quotation document and carried into revision copies.
- PDF: the item-page summary prints only applicable adjustment rows, with the legacy 0% SST row when both inputs are blank.

Baseline: V5.00.39. No database migration required.
