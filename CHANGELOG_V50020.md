# KeySuite V5.00.20

V5.00.20 is a focused Compare View label correction built from V5.00.19.

- Displays `CR`, `KV`, `BFI`, `BGF`, `ISO`, `ES` and `GWS` in uppercase.
- Preserves `CHC G1`, `CHC G2`, `KeyPLC` and the remaining product labels.
- Does not change category codes, pricing rules, Supabase data, permissions, product functions or the frozen quotation PDF layout.
- No database migration or Edge Function deployment is required.
