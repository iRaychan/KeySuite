# KeySuite V5.00.80 Phase 02 — review candidate

Continuation correction: actual Safari testing reproduced HMS still displaying BFI in the Product Curve title and Selected Pump. The Product Series overhaul had a separate aliasModel implementation with an incorrectly escaped word-boundary expression. It now delegates to the shared configuration resolver. Retested in Safari: title, header, selected model and alternatives consistently show HMS. Packages rebuilt solely because this genuine defect was identified.

Baseline: V5.00.79. No deployment, migration or production record changes.

- Item serialization now preserves internalRemark for manual items as well as every other item type. Retains source payload metadata rather than dropping unknown item fields.
- Assign stable quoteItemId values; duplicates/clones receive independent IDs while restored items retain theirs.
- Sealed quotations permit opening Remarks, with read-only text, a lock label and no enabled Save button. Existing mutation guards remain.
- Selector aliases reuse the existing configuration-based displayModelAlias resolver. Explicit selling-series mappings take precedence in brandContext. Alias text caches detect selector rerenders rather than restoring stale text.
- Complete pumpset description assembly accepts the component's existing commercial pump description instead of requiring a B.G.Reich prefix or generating that brand as a fallback.
- Version, manifest and service-worker cache advanced to V5.00.80.

Internal Item Remarks remain internal, excluded from customer PDFs under the existing formatting rule. Missing historical remarks cannot be reconstructed by this patch.

See V5.00.80_TEST_REPORT.md for the limited verified scope and outstanding acceptance work. This package is not certification that every requested global route is fixed.
