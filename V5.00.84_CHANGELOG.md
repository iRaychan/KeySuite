# KeySuite V5.00.84

Baseline: KeySuite V5.00.83 FULL. Upgrade target: V5.00.83 only.

## Operating speed

- Shared operating-frequency policy: normal default 50 Hz, maximum 60 Hz, decimal values retained, including 50.01 Hz.
- Existing inputs turn red strictly above 50 Hz. Values above 60 Hz remain invalid and leave the last valid curve unchanged; no popup, shortcut or new control.
- Existing Hz/RPM selectors retain decimal precision on round trips. Reference text now includes 60 Hz instead of calling 50 Hz the maximum.
- CHC C4/C6, BFI, CR, KV, BGF, BSW, ES/ISO and G engine entry points use the shared control. Configured commercial brands sharing those engines inherit it.
- Existing Enhanced mode, hydraulic formulas, performance availability and source catalogue values are retained. No new performance data has been created. Red fill indicates frequency only; it does not certify pump/motor suitability.

## Commercial quotation identity

- Capture the selected commercial identity before selector messages can trigger navigation or asynchronous routing.
- Keep that snapshot authoritative after quotation row creation, late field assignments, legacy brand wrappers and assembly conversion.
- Preserve explicit brandless selections. Remove pricing/master-brand fallbacks from the commercial quotation wrapper.
- Use the same description resolver for legacy quotation descriptions and future configured series, without a family whitelist.
- Preserve each component's identity in mixed systems; grouped BOM descriptions are not rebranded from the active selection.
- Quotation brand lists use commercial snapshots rather than hydraulic/pricing-source brand names.
- Preserve manually edited descriptions and saved quotation snapshots. Existing incorrect historical descriptions without reliable identity are not guessed from the currently selected brand.

## Installation and data

Extract FULL to a clean application directory, or overlay UPGRADE onto V5.00.83, preserving the relative paths. No database migration, data seed or record reset is required. Do not execute inherited SQL scripts as part of this upgrade.

No deployment or production database operation was performed. Browser visual checks, live history persistence and actual PDF export remain unverified; see the test report.

Archive SHA-256 checksums accompany the ZIPs in V5.00.84_SHA256SUMS.txt. Each ZIP contains V5.00.84_FILE_SHA256SUMS.txt for changed/new release files; archive checksums cannot be embedded in the archives they checksum.
