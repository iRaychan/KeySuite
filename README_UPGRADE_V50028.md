# KeySuite V5.00.28 Upgrade

This package upgrades a complete KeySuite V5.00.27 installation to V5.00.28.

1. Back up the existing V5.00.27 installation.
2. Copy the contents of this package over the installation root, preserving directory paths.
3. Allow changed files to replace their V5.00.27 counterparts.
4. Reload KeySuite and verify that the sign-in boundary displays V5.00.28.

No Supabase deployment or database migration is required.

Do not apply this upgrade package to a version older or newer than V5.00.27. Use the full-build package instead.
