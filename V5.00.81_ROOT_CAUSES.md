# Root-cause findings

## Bug 001

Live Safari V5.00.80 was reproduced from Brandless HMS 10-3T. The frame used selector-bfi/product.html; the title and selected model displayed BFI 10-3T, the header HMS Series, and alternatives mixed HMS names with BFI series labels. Reverse B.G.Reich BFI worked in that observed sequence.

Relevant paths: bfi-v42302.js openCurve; v394411-product-curve.js buildPresentation/open/onMessage; v40001-product-series-overhaul.js snapshot/finalizeFrame/applyScreenIdentity; v40001-selector-brand.js modelAlias; v40001-multibrand.js displayModelAlias/decorateProductDisplay.

The old alias used configured masterSeries as the replacement token, although the hydraulic frame supplies its own family token. A mapping whose configured master is HMS can therefore leave BFI unchanged. Reproduced in isolation with master_series=HMS and selling_series=HMS. A newly configured SOURCE→FUTURE mapping sharing BFI hydraulics is also covered.

An additional reload test exposed v393MasterText restoring a cached `CHC Curve` outer title after the HMS frame initialized correctly. The outer title now reads the active frame identity. The previous correction delegated one alias function but did not address the mismatch between configured and hydraulic tokens or this cached title writer.

Exact production configuration records and served JavaScript bytes were not exported; these findings combine observed live behavior with source inspection and isolated reproductions.

## Bug 002

Live Safari V5.00.80: Megaflow ES 40-16, complete set, 30 m³/hr @ 30 Mtr. Quote generated `B.G.Reich End Suction Pump Model: ES 40-16`.

pricing.js esDescription hardcoded B.G.Reich. app.js routeEsSelection resolved and stored the selected brand but called that description generator without applying the brand. assembly.js pumpDescriptionParts preserved that incorrect line; quotePumpsetSelection transferred it as an ASSEMBLY record. Legacy mapRowIdentity and repairQuotationBrands skip ASSEMBLY records. The previous formatter-only preservation fix therefore preserved the upstream error.

The selected identity is now applied before component grouping, then retained as a serializable component/item snapshot. Generated descriptions use configuration, while pricing and hydraulics continue using their existing sources. Brandless is an intentional empty prefix. Mixed systems retain separate component snapshots; no blanket system-brand replacement is introduced.
